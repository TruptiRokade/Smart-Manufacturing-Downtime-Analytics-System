# Smart Manufacturing Downtime Analytics System

## Project Overview

The Smart Manufacturing Downtime Analytics System is a Data Analytics project designed to analyze machine downtime, maintenance costs, production losses, and equipment failure patterns across multiple manufacturing plants in India.

The objective of this project is to identify operational inefficiencies, understand root causes of machine failures, monitor maintenance performance, and provide actionable insights to improve production efficiency.

---

## Business Problem

Manufacturing plants experience production losses due to machine breakdowns, unplanned downtime, and maintenance delays. These issues increase operational costs and reduce productivity.

This project helps answer key business questions such as:

* Which plant experiences the highest downtime?
* Which machine types fail most frequently?
* What are the major root causes of failures?
* How much production loss occurs due to downtime?
* Which shifts experience more breakdowns?
* How effective is the maintenance team?
